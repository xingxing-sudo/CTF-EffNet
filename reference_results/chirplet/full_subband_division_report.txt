📌 步骤2：物理语义与寻优约束设定
=====================================================================================
约束1：三通道必须以0为中心对称
  → 对应物理意义：负向调频（减速）、稳态巡航（调频≈0）、正向调频（加速）
约束2：三类样本均非空，确保每个通道均承载有效工况
  → 避免出现退化通道，保证三通道物理可解释性
约束3：中间通道宽度完全由数据驱动，不预设最小啁啾基数
  → 尊重港口船舶真实调频极其微弱的物理现实

寻优准则：在满足对称且三类非空的前提下，选取类间方差最大的阈值
  → 兼顾物理合理性与统计最优性
=====================================================================================

=====================================================================================
📌 步骤3：数据驱动的最优阈值寻优（类间方差最大化）
=====================================================================================
寻优范围：tau ∈ [0.05, 0.35] Hz/s，步长：0.001
优化目标：三类样本的类间方差最大 → 三类特征区分度最高
约束：三类均非空（不限制中间通道宽度，以真实数据分布为准）
-------------------------------------------------------------------------------------
✅ 寻优完成！最优对称阈值：tau = 0.057 Hz/s
   对应物理分界：c₁ = -0.057 Hz/s，c₂ = 0.057 Hz/s
   最大类间方差：0.004460

   三类样本占比：
     低啁啾（负向机动）：17.31%
     中啁啾（稳态巡航）：65.43%
     高啁啾（正向机动）：17.26%

💡 本步结论：
  该阈值是三类调频特征统计区分度最高的分界，完全由数据驱动；
  中间通道较窄反映了港口船舶调频极其微弱的物理现实，两侧通道虽宽但集中了机动特征。
=====================================================================================

📌 步骤4：连续物理阈值 → 64维离散啁啾基索引映射
=====================================================================================
全局啁啾范围：[-5.0, 5.0] Hz/s
离散啁啾基总数：64 个（索引0 ~ 63）
相邻索引物理步长：0.1587 Hz/s
映射公式：idx = (c - (-5.0)) / 0.1587
-------------------------------------------------------------------------------------
负向分界 c = -0.0570 Hz/s
  计算：idx = (-0.0570 - (-5.0)) / 0.1587 = 31.141
  四舍五入后索引：31

正向分界 c = 0.0570 Hz/s
  计算：idx = (0.0570 - (-5.0)) / 0.1587 = 31.859
  四舍五入后索引：32
